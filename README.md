# Road Empire 🚗
Offline Android 13 compatible racing game. Native Android Canvas, no network permission. Controls: wheel, gas, brakes, P/D/R/N, parking brake, 4x4 on supported vehicles; garage, races, money and difficulty. Stylized 2D pseudo-3D visuals, not photorealistic or licensed vehicle models.

## APK
Open Actions > Build Android APK > latest successful run > Artifacts > RoadEmpire-Android13-APK, extract ZIP, install app-debug.apk. Internet is needed only to download/build, not to play.
